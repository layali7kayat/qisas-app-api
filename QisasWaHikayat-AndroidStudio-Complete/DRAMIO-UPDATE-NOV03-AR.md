# تحديث Dramio — 3 نوفمبر 2026

## ما تم تحديثه
- توحيد خلفية شاشة بدء التشغيل مع لون أيقونة Dramio الأصفر.
- إضافة إعدادات Splash Screen لأجهزة Android 12 وما بعدها، وخلفية بديلة للإصدارات الأقدم.
- تفعيل وضع الشاشة الكاملة وإخفاء شريطي الحالة والتنقل مع إظهارهما مؤقتاً بالسحب.
- تحسين بطاقات القصص الأفقية: مقاس موحد، أغلفة بنسبة 3:4، تباعد أوضح وخط أكبر.
- إضافة شريط تنقل سفلي بخمس خانات: الرئيسية، التصنيفات، المفضلة، بحث، حسابي.
- إضافة صفحة حسابي كواجهة تمهيدية لتسجيل Google.

## مهم بخصوص تسجيل Google ومزامنة بيانات الزائر
صفحة الحساب وزر Google موجودان كواجهة أولية فقط. لم يتم تفعيل المصادقة الفعلية أو مزامنة بيانات الحساب بعد؛ يلزم إعداد OAuth Web Client ID في Google Cloud، ثم تنفيذ التحقق من Google ID token في Cloudflare Worker وربط المستخدم بقاعدة D1. لا تعرض الواجهة الحالية نجاح تسجيل دخول وهمياً.

## ملاحظات البناء
- تم الحفاظ على applicationId الحالي: `ap4221554.cyq`.
- تم الحفاظ على Cloudflare Worker الحالي وواجهات API الحالية.
- يلزم فتح المشروع في Android Studio وتنفيذ Gradle Sync ثم Build > Make Project.
- لم يتوفر Gradle/Android SDK في بيئة إعداد الملف، لذلك لم يتم التحقق من APK هنا.


## المرحلة التالية – تسجيل الدخول بحساب Google
- تفعيل Google Credential Manager باستخدام Web Client ID.
- إضافة إدخال اسم العرض بعد اختيار حساب Google.
- إرسال Google ID Token إلى Cloudflare Worker والتحقق منه لدى Google قبل قبول الحساب.
- إنشاء/تحديث سجل المستخدم في D1 مع بريد موثّق ومعرّف Google فريد.
- اعتماد صورة Dramio الافتراضية وعدم جلب صورة الملف الشخصي من Google.
- إضافة `backend/cloudflare/migration_users.sql` وتعليمات النشر في `GOOGLE-AUTH-SETUP-AR.md`.

**مهم:** هذه تعديلات مصدر تحتاج نشر Worker وترحيل D1 يدويًا وفق الدليل. لم يتم بناء التطبيق بواسطة Gradle أو اختباره على جهاز في بيئة الإنشاء، كما أن هذا الإصدار لا ينشئ جلسة خادم طويلة الأجل ولا يربط المفضلة/التعليقات بالحساب بعد.
