# تحديث مشغل Dramio

تمت إعادة تصميم شاشة الاستماع داخل `EpisodePlayerScreen` مع الإبقاء على مصدر التشغيل والتحكم الحاليين.

## ما تغير
- شريط علوي يحمل هوية Dramio وحالة التشغيل.
- غلاف كبير للقصة مع معالجة بصرية داكنة.
- عنوان القصة وبيانات الحلقة الحالية.
- شريط تقدم واضح مع الوقت المنقضي والمدة.
- زر تشغيل/إيقاف مؤقت بارز.
- أزرار الانتقال بين الحلقات والتحكم بسرعة التشغيل.
- قائمة حلقات بتمييز الحلقة الحالية وإمكانية توسيع القائمة.
- قصص مقترحة بتصميم بطاقات مدمج.
- إزالة موضع الإعلان من أعلى مشغل الصوت للحفاظ على تركيز تجربة الاستماع.

## ملاحظات
- لم يتم تغيير واجهة Cloudflare API أو طريقة تحميل ملفات الصوت.
- لم يتم تغيير Media3 / ExoPlayer أو منطق التنقل بين الحلقات.
- لم تتم إضافة مؤقت نوم أو مفضلة داخل المشغل لأنهما يحتاجان إلى وظائف وربط بيانات منفصلين.
- يلزم فتح المشروع في Android Studio وتشغيل Gradle Sync ثم Build للتحقق النهائي على بيئة Android الفعلية.
