# مرجع التصميم الأصلي

هذه الملاحظات مستخلصة من ملفات تصميم الموقع الأصلي، ولا تُستخدم كواجهات تشغيل داخل تطبيق Android.

- الخلفية الرئيسية: `#101113`.
- خلفية البطاقات: `#1C1E21`.
- لون التمييز الذهبي: `#F2C94C`.
- النص الأساسي: `#F5F1E8`.
- النص الثانوي: `#A8A8AD`.
- شريط علوي داكن، وبطاقات قصص بصور مربعة، وتصنيفات مستقلة، وتفاصيل قصة مع وصف وفصول ومشغل صوت.
- القائمة الأصلية تضم البحث والتصنيفات وقوائم المستخدم وسجل المشاهدة والمشاهدة لاحقًا والمفضلة.

التنفيذ النهائي لكل التفاصيل المرئية يحتاج مراجعة بصرية على جهاز Android مقابل لقطات المشروع الأصلي.
